# Number Guessing Game
## Project Description
This is a simple Python mini project in which the computer randomly selects a number between 1 and 100, and the player tries to guess it.

## Features
- Generates a random number.
- Tells the player whether the guess is too high or too low.
- Checks for invalid input.
- Counts the number of valid attempts.
- Displays a congratulatory message when the number is guessed correctly.

## Technologies Used
- Python
- `random` module
- Functions, loops, conditional statements, and exception handling

## How to Run
1. Make sure Python is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python guessing_game.py
```
